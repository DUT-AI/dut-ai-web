# Môi trường python

## Python environment là gì?

Python Environment (môi trường Python) là không gian độc lập chứa:

- Phiên bản Python riêng (ví dụ: Python 3.8, 3.10, 3.12…)
- Các thư viện (packages) được cài đặt trong môi trường đó

👉 Mục đích: Tách biệt các dự án để tránh xung đột thư viện.
Ví dụ:

Dự án A cần Django==2.2

Dự án B cần Django==4.0
→ Không thể cài chung một chỗ, nên phải dùng môi trường ảo – tức là không gian riêng biệt chứa **phiên bản Python và thư viện riêng**, tách biệt với hệ thống chính ( Virtual Environment) 

```bash
# Tạo
python -m venv <tên môi trường ảo>

# Kích hoạt 
source <tên môi trường ảo>/bin/activate # linux, macos
.venv\Scripts\Activate.ps1 # window

# Kiểm tra môi trường ảo
which python 

# git ignore các file thư viện
echo "*" > .venv/.gitignore 
```

## Pip

PIP (Pip Installs Packages) là trình quản lý thư viện mặc định của Python.

Cú pháp cơ bản:

```bash
pip install numpy
pip uninstall pandas
pip list
pip freeze > requirements.txt
pip install -r requirements.txt
```

✔ Ưu điểm:

- Đơn giản, có sẵn khi cài Python
- Phù hợp cho các dự án nhỏ và nhanh gọn

❌ Nhược điểm:

- Pip chỉ kiểm tra dependency của từng package riêng, dễ dẫn xung đột version giữa các li
- Nhiều thư viện khoa học như NumPy, SciPy, OpenCV, PyTorch… thực ra được viết một phần lớn bằng C hoặc C++. Khi bạn cài bằng pip, pip sẽ tải mã nguồn gốc (C/C++ + Python) về và cố gắng biên dịch thành file nhị phân phù hợp với hệ điều hành của bạn. Nếu máy thiếu **compiler (gcc, clang, Visual Studio Build Tools…) hoặc thiếu thư viện - hệ thống**, quá trình build sẽ **bị lỗi** → *Installation Error*.

## Conda

- **Conda** là một **trình quản lý môi trường + thư viện** mạnh mẽ hơn Pip.

```bash
# Tạo môi trường
conda create -n <tên môi truờng> python=3.10

# Kích hoạt
conda activate <tên môi truờng>

# Cài package
conda install numpy

conda export > environment.yml

conda env create -f environment.yml
```

✔ Ưu điểm:

- **Quản lý cả Python + thư viện trong môi trường riêng biệt**
- Có thể cài **package không phải Python** (VD: OpenCV, CUDA, libgcc…)
- Conda **không tải mã nguồn**, mà tải **bản đã được biên dịch sẵn**, phù hợp đúng với hệ điều hành và kiến trúc CPU của bạn.
- Bạn **không cần compiler hay dependency hệ thống** → Cài xong là **chạy ngay**.

❌ Nhược điểm:

- Chiếm dung lượng nặng
- Tốc độ cài đặt hơi chậm hơn pip

## Uv

- **UV** là **trình quản lý thư viện & môi trường thế hệ mới**, nhanh hơn **pip** và **conda** rất nhiều.
- Được gọi là **"Rust-based ultra-fast package manager"**

```bash
uv init myproject      # Tạo project Python kèm môi trường
uv add numpy           # Cài thư viện (nhanh hơn pip)
uv run script.py       # Chạy trong môi trường tự động
```

✔ Ưu điểm:

- **Nhanh hơn pip 10–100 lần**
- **Tạo môi trường tự động**, không cần `venv` hay `conda`
- Có thể dùng thay luôn pip + conda

❌ Nhược điểm:

- Còn mới → Ít tài liệu hơn
- Một số thư viện hiếm có thể chưa hỗ trợ

# Ép kiểu

**Ép kiểu** (type casting / type conversion) là quá trình **chuyển giá trị từ kiểu dữ liệu này sang kiểu dữ liệu khác**.

Python hỗ trợ **2 loại ép kiểu**:

1. **Ép kiểu tường minh (explicit casting)** – do lập trình viên chủ động thực hiện bằng các hàm dựng sẵn.

```python
# Số sang chuỗi
a = 10
b = str(a)
print(b, type(b))  # "10" <class 'str'>

# Chuỗi sang số
c = "3.14"
d = float(c)
print(d, type(d))  # 3.14 <class 'float'>

# Danh sách sang tập hợp
e = [1, 2, 2, 3]
f = set(e)
print(f)  # {1, 2, 3}
```

1. **Ép kiểu ngầm định (implicit casting)** – Python tự thực hiện khi cần. Python **tự động** chuyển kiểu khi cần để đảm bảo tính chính xác trong phép toán.

```python
x = 5        # int
y = 2.0      # float
z = x + y    # float + int → float
print(z)     # 7.0
print(type(z))  # <class 'float'>
```

# Overflow và Underflow

- **Overflow** xảy ra khi **giá trị vượt quá giới hạn tối đa** mà kiểu dữ liệu có thể biểu diễn.
- Underflow xảy ra khi **giá trị nhỏ hơn giới hạn nhỏ nhất** có thể biểu diễn

| Loại dữ liệu | Overflow xảy ra? | Underflow xảy ra? | Ghi chú |
| --- | --- | --- | --- |
| **int** | Không (Python tự mở rộng kích thước) | Không | Không giới hạn bit |
| **float** | Có (ra `inf`) | Có (về `0.0`) | Chuẩn IEEE 754 |
- Python lưu int như một đối tượng (object), chứ không phải kiểu dữ liệu cố định trên CPU.
Nội bộ, nó quản lý một mảng các “digit” (thường là 30 bit hoặc 60 bit mỗi phần),
và tự động mở rộng mảng đó khi số quá lớn.
- Khi bạn cần tốc độ cao (ví dụ tính toán khoa học), Python thường dùng:
    - numpy.int32, numpy.int64 → để cố định kích thước, tăng hiệu suất.
    - decimal.Decimal → nếu muốn độ chính xác cao cho số thực (tiền tệ, tính toán tài chính)

# Function

Function (hàm) là một khối mã (code block) được đặt tên, dùng để thực hiện một nhiệm vụ cụ thể.
Khi cần, ta gọi hàm để chạy thay vì viết lại cùng đoạn code nhiều lần.

👉 Nói cách khác: Function giúp tái sử dụng code và tổ chức chương trình gọn gàng hơn.

```python
def <tên_hàm>(<tham_số>):
    # khối lệnh thực thi
    return <giá_trị_trả_về>
```

## Tham số và đối số

- **Tham số (Parameter)**: biến được định nghĩa trong hàm
- **Đối số (Argument)**: giá trị truyền vào khi gọi hàm

```python
def add(a, b):      # a, b là THAM SỐ
    return a + b

result = add(3, 5)  # 3, 5 là ĐỐI SỐ

```

## Default parameters (tham số mặc định)

```python
def greet(name="Guest"):
    print("Hello,", name)

greet()           # Hello, Guest
greet("Phước")    # Hello, Phước
```

Khi nào cần dùng? Tạo sao phải dùng?

1. Khi muốn giữ giao diện hàm gọn gàng

Ví dụ hàm logging, phần lớn trường hợp chỉ cần log cơ bản, nhưng có thể mở rộng khi cần:

```python
def log(message, level="INFO"):
    print(f"[{level}] {message}")

log("System started")          # [INFO] System started
log("Error occurred", "ERROR") # [ERROR] Error occurred
```

1. Khi muốn chỉnh sửa thêm các tham số không quan trọng, nhưng không muốn sửa lại toàn bộ chỗ gọi hàm

**Lưu ý** 

Không nên dùng giá trị mặc định là object có thể thay đổi (mutable) như list, dict, set — vì nó chỉ được khởi tạo 1 lần duy nhất.

```python
# ⚠️ Sai
def add_item(item, my_list=[]):   
    my_list.append(item)
    return my_list

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2]  ← danh sách bị “dính” giá trị cũ!

# Đúng 
def add_item(item, my_list=None):
    if my_list is None:
        my_list = []
    my_list.append(item)
    return my_list

```

## **Hàm với số lượng tham số linh hoạt**

*args → nhận nhiều đối số dạng tuple

**kwargs → nhận nhiều đối số dạng từ khóa (dict)

```python
def info(name, *args, **kwargs):
    print("Tên:", name)
    print("Args:", args)
    print("Kwargs:", kwargs)

info("Nguyên", 21, "Đà Nẵng", hobby="AI", lang="Python")

Tên: Nguyên
Args: (21, 'Đà Nẵng')
Kwargs: {'hobby': 'AI', 'lang': 'Python'}

```

Khi nào cần dùng?

1. Khi bạn muốn chuyển tiếp tham số linh hoạt giữa các hàm → dùng *args, **kwargs để truyền toàn bộ tham số cho hàm khác mà không cần liệt kê lại

```python
import time

def time_logger(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        print(f"Bắt đầu chạy: {func.__name__}")
        
        result = func(*args, **kwargs)   # Gọi hàm gốc với mọi tham số
        
        end = time.time()
        print(f"Hoàn thành {func.__name__} trong {end - start:.4f} giây\n")
        return result
    return wrapper

@time_logger
def compute_sum(n):
    return sum(range(n))

@time_logger
def greet(name, message="Hello"):
    print(f"{message}, {name}!")

# --- Test ---
compute_sum(1_000_000)
# Bắt đầu chạy: compute_sum
# Hoàn thành compute_sum trong 1.2 giây
greet("Nguyên", message="Chào bạn")

=> Ứng dụng thực tế: logging, đo thời gian, kiểm tra quyền, tracing trong hệ thống AI/ML pipeline.
```

1. Trong lập trình hướng đối tượng (OOP), **kwargs thường dùng để giữ khả năng mở rộng khi subclass có thêm thuộc tính:

```python
class Classifier
	def __init__(self):
		pass
	def predict(self, image, **kwargs):
		pass

class MobileNet(Classifier):
	def __init__(self):
		super().__init__()
		
	def predict(self, image, **kwargs):
		threshold_conf = kwargs.get("threshold_conf", 0.6)
		...
		
class MyModel(Classifier):
	def __init__(self):
		super().__init__()
		
	def predict(self, image, **kwargs):
		threshold_conf = kwargs.get("threshold_dog", 0.2)
		threshold_conf = kwargs.get("threshold_cat", 0.3)
		...
```

# Loop

## 1. Khái niệm

**Loop (vòng lặp)** là cấu trúc cho phép **thực thi lặp lại một khối lệnh** nhiều lần

cho đến khi **điều kiện dừng** được thỏa mãn.

Python có **2 loại vòng lặp chính:**

1. `for` loop – lặp qua **các phần tử có thể duyệt (iterable)**
2. `while` loop – lặp **khi điều kiện còn đúng**

---

## 2. `for` loop

### 🔹 Cú pháp:

```python
for variable in iterable:
    # khối lệnh được lặp

```

### 🔹 Ví dụ 1: Lặp qua danh sách

```python
fruits = ["apple", "banana", "cherry"]
for f in fruits:
    print(f)
```

➡️ Output:

```
apple
banana
cherry

```

### 🔹 Ví dụ 2: Lặp với `range()`

```python
for i in range(5):  # 0 → 4
    print(i)
```

➡️ Output:

```
0
1
2
3
4
```

---

## 3. `while` loop

### 🔹 Cú pháp:

```python
while condition:
    # khối lệnh lặp

```

### 🔹 Ví dụ:

```python
count = 0
while count < 3:
    print("Hello", count)
    count += 1

```

➡️ Output:

```
Hello 0
Hello 1
Hello 2

```

⚠️ Nếu điều kiện **không bao giờ sai**, vòng lặp sẽ **chạy vô hạn (infinite loop)**.

---

## 4. Từ khóa điều khiển vòng lặp

### 🔹 `break` → Dừng vòng lặp ngay lập tức

```python
for i in range(10):
    if i == 5:
        break
    print(i)

```

## With

Từ khóa **`with`** trong Python được dùng để **quản lý tài nguyên tự động**.

Cụ thể, nó đảm bảo rằng:

- tài nguyên sẽ được **mở ra khi bắt đầu khối lệnh**,
- và **tự động giải phóng (đóng)** khi kết thúc khối,
    
    kể cả khi có **lỗi xảy ra** giữa chừng.
    

### ❌ Không dùng `with`:

```python
f = open("data.txt", "r")
content = f.read()
f.close()
```

Nếu lỡ có lỗi xảy ra **trước khi gọi `f.close()`**, file sẽ không được đóng → gây **rò rỉ tài nguyên**.

---

### ✅ Dùng `with`:

```python
with open("data.txt", "r") as f:
    content = f.read()
    print(content)
    
content ...
```

Khi thoát khỏi khối `with` (kể cả bị lỗi), Python **tự động gọi `f.close()`**.

👉 Cơ chế này được gọi là **Context Management Protocol**, gồm **hai phương thức đặc biệt**:

| Phương thức | Mục đích |
| --- | --- |
| `__enter__()` | Chạy khi bắt đầu `with` |
| `__exit__()` | Chạy khi thoát khỏi `with` (kể cả lỗi) |

### Ví dụ: quản lý kết nối giả lập

```python
class MyConnection:
    def __enter__(self):
        print("Kết nối được mở")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Kết nối đóng lại (dù có lỗi hay không)")

    def send(self, data):
        print(f"Gửi dữ liệu: {data}")
```

### Dùng thử:

```python
with MyConnection() as conn:
    conn.send("Hello Server")
    # raise ValueError("Lỗi giả lập")  # thử bật dòng này để thấy __exit__ vẫn chạy
```

➡ Output:

```
Kết nối được mở
Gửi dữ liệu: Hello Server
Kết nối đóng lại (dù có lỗi hay không)
```

---

# 🔹 4. Truyền lỗi ra ngoài hoặc xử lý trong `__exit__`

`__exit__()` có thể:

- **Trả về `False`** → lỗi sẽ **được ném ra ngoài** (mặc định)
- **Trả về `True`** → lỗi sẽ **bị chặn lại**, không lan ra ngoài

Ví dụ:

```python
class SafeBlock:
    def __enter__(self):
        print("Bắt đầu khối an toàn")
    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Đã xảy ra lỗi:", exc_val)
        return True  # Không ném lỗi ra ngoài

with SafeBlock():
    1 / 0  # lỗi chia 0
print("Chương trình vẫn tiếp tục")
```

➡ Output:

```
Bắt đầu khối an toàn
Đã xảy ra lỗi: division by zero
Chương trình vẫn tiếp tục
```

```python
class NegativeNumberError(Exception):

def check_positive(x):
    if x < 0:
        raise NegativeNumberError("Giá trị âm không hợp lệ!")
    print("Giá trị hợp lệ:", x)

try:
    check_positive(-5)
except NegativeNumberError as e:
    print("Lỗi:", e)
```

# Module và Package

## 1. Module là gì?

**Module** = một **file Python (.py)** chứa code (biến, hàm, class, …) mà bạn có thể **nhập (import)** và **tái sử dụng** ở file khác.

Ví dụ:

```python
# 📁 math_utils.py
def add(a, b):
    return a + b

def mul(a, b):
    return a * b
```

File khác:

```python
# 📁 main.py
import math_utils

print(math_utils.add(3, 4))  # 👉 7
print(math_utils.mul(2, 5))  # 👉 10

# Hoặc 
from math_utils import add, mul
print(add(3, 4))  # 👉 7
print(mul(2, 5))  # 👉 10

# Hoặc 
from math_utils import *
```

📌 **Hiểu đơn giản:**

> Một file .py = Một module.
> 

---

## 2. Package là gì?

**Package** là **một thư mục (folder)** chứa **nhiều module** (và/hoặc subpackage).

Một thư mục được coi là package khi nó có file đặc biệt:

```python
__init__.py
```

Ví dụ:

```
myapp/
│
├── __init__.py
├── utils/
│   ├── __init__.py
│   ├── file_utils.py
│   └── math_utils.py
└── main.py
```

---

## 3. Cách import trong package

Giả sử `file_utils.py` có:

```python
def read_file(path):
    with open(path) as f:
        return f.read()

```

và `math_utils.py` có:

```python
def square(x):
    return x * x

```

Khi đó trong `main.py`:

```python
from utils.file_utils import read_file
from utils.math_utils import square

print(square(5))
print(read_file("data.txt"))

```

🎯 Kết quả: bạn có thể chia code thành **module nhỏ gọn, dễ bảo trì**.

---

## 4. `__init__.py` để làm gì?

File `__init__.py` giúp Python nhận biết đây là **package hợp lệ**.

Bạn có thể dùng nó để:

- **Khởi tạo package** (ví dụ: log khi import, load config)
- **Tái xuất module** (re-export) để import gọn hơn.

Ví dụ:

```python
# utils/__init__.py
from .math_utils import square
from .file_utils import read_file
```

Khi đó bạn có thể import **ngắn hơn**:

```python
from utils import square, read_file
```

## Vòng đời của 1 module khi import

Mỗi module chỉ được import và thực thi *một lần duy nhất* trong suốt vòng đời chương trình.

```

```


## 2. Khi bạn chạy:

```bash
python D.py
```

Hãy xem điều gì thực sự diễn ra bên trong Python.

---

### 🔹 Bước 1: Python chạy D.py

- Nó thấy `import B` → bắt đầu load module `B`.

---

### 🔹 Bước 2: Python import B

- Trong `B.py`, có `import A` → Python load `A`.

---

### 🔹 Bước 3: Python import A (lần đầu tiên)

- `A` chưa có trong bộ nhớ, nên Python:
    - Tạo object module mới `A`
    - Thực thi code trong `A.py`
        
        👉 In ra:
        
        ```
        A is being imported
        
        ```
        
    - Lưu kết quả module `A` vào cache `sys.modules["A"]`.

---

### 🔹 Bước 4: Quay lại B

- Tiếp tục thực thi phần còn lại của `B.py`
    
    👉 In ra:
    
    ```
    B is being imported
    
    ```

### 🔹 Bước 5: Quay lại D, tiếp tục `import C`

- Trong `C.py` cũng có `import A`, nhưng lúc này…
    
    🧠 Python kiểm tra `sys.modules`:
    
    ```python
    if "A" in sys.modules:
        reuse_existing_module()
    
    ```
    
    → `A` **đã được import rồi**, nên:
    
    - **Không thực thi lại `A.py`**
    - **Dùng lại module `A` có sẵn trong bộ nhớ**

👉 Do đó, `A is being imported` **chỉ in ra 1 lần duy nhất**.

## 🔁 4. Cơ chế thực tế bên trong

Python duy trì một **cache toàn cục** gọi là `sys.modules`,

nó là một dictionary ánh xạ tên module → object module đã load.

```python
import sys
print(sys.modules.keys())
```

Ví dụ (một phần nhỏ):

```
dict_keys(['sys', 'os', 'A', 'B', 'C', 'D', '__main__'])
```

---

## 🧱 5. Lợi ích của cơ chế này

✅ **Hiệu suất cao hơn** — mỗi module chỉ load/parse/compile một lần.

✅ **Đảm bảo tính nhất quán** — các module chia sẻ cùng một “instance” của A.

✅ **Tránh vòng lặp vô hạn** trong trường hợp import đệ quy.

## ⚠️ 6. Nếu bạn *muốn chạy lại* code trong A?

Bạn có thể dùng:

```python
import importlib
importlib.reload(A)
```

Điều này sẽ **tải lại và thực thi lại module A**, thường dùng trong môi trường interactive hoặc debug.
