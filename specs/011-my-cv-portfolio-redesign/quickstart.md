# Quickstart: Testing & Verifying the My-CV Portfolio Redesign

## 1. Local Development Run
Start the development server:
```bash
cd frontend && npm run dev
```

## 2. Navigating to Member Portfolio
Visit any member's portfolio page:
- `http://localhost:3000/members/nguyenhuynh` (or active username in database)

## 3. Visual Verification Checklist
1. **Background**: Observe the deep cosmos gradient background and subtle starry particle animation.
2. **Hero**: Verify the Typewriter effect rotating through titles and the wave emoji animation.
3. **About & Skills**:
   - Verify the "Know Who I'M" card text.
   - Verify the "Professional Skillset" and "Tools I use" grid cards displaying icons with hover glow.
   - Verify the "Days I Code" GitHub calendar rendering contributions with the blue color scale.
4. **Projects**: Check the "Recent Works" cards with thumbnails, GitHub link, Live Demo button, and club badges.
5. **Resume**: Verify the "Download CV" action button triggers file download.
6. **Console**: Confirm zero React hydration errors and zero script errors.
