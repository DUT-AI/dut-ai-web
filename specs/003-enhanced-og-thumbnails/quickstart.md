# Quickstart Validation Guide: Enhanced OpenGraph Thumbnails

**Feature**: `003-enhanced-og-thumbnails`  
**Date**: 2026-10-15  
**Status**: Completed  

---

## Prerequisites

1. Local frontend development server is running:
   ```bash
   make frontend
   # or
   cd frontend && npm run dev
   ```
2. Verify frontend is accessible at `http://localhost:3000`.

---

## Validation Scenario 1: Preview Generator with Club Logo & Fallback Avatars

**Goal**: Confirm that the preview endpoint generates a valid PNG image containing the official club logo and multi-author fallback initials.

1. Send an HTTP request to the preview endpoint with Vietnamese names:
   ```bash
   curl -I "http://localhost:3000/api/og/blog/preview?title=T%E1%BB%91i+%C6%B0u+h%C3%B3a+M%C3%B4+h%C3%ACnh+AI&author=Nguy%E1%BB%85n+V%C4%83n+An&author=Hu%E1%BB%B3nh+Ph%C6%B0%E1%BB%9Bc+Nguy%C3%AAn"
   ```
2. **Expected Response**:
   - HTTP Status `200 OK`
   - Header `Content-Type: image/png`
   - Content length > 15,000 bytes
3. Open the preview URL in a browser:
   `http://localhost:3000/api/og/blog/preview?title=Tối+ưu+hóa+Mô+hình+AI&author=Nguyễn+Văn+An&author=Huỳnh+Phước+Nguyên`
   - Confirm the official DUT AI Club robot logo appears in the top-left corner.
   - Confirm two avatar circles appear: one with initial **"A"** (for An) and one with **"N"** (for Nguyên).

---

## Validation Scenario 2: Canonical Blog OpenGraph Endpoint

**Goal**: Validate the production slug endpoint with database-backed authors and caching headers.

1. Fetch a blog OG thumbnail by slug:
   ```bash
   curl -I "http://localhost:3000/api/og/blog/xay-dung-he-thong-ai"
   ```
2. **Expected Response**:
   - HTTP Status `200 OK`
   - Header `Cache-Control: public, max-age=31536000, immutable`
   - Header `Content-Type: image/png`

---

## Validation Scenario 3: Social Media Metadata Verification

**Goal**: Ensure Facebook and Twitter scraper tags are completely populated.

1. Inspect metadata generated by the blog page:
   ```bash
   curl -s "http://localhost:3000/blog/xay-dung-he-thong-ai" | grep -E 'property="og:image|name="twitter:'
   ```
2. **Expected Tags in HTML**:
   - `<meta property="og:image" content="https://.../api/og/blog/xay-dung-he-thong-ai" />`
   - `<meta property="og:image:width" content="1200" />`
   - `<meta property="og:image:height" content="630" />`
   - `<meta property="og:image:type" content="image/png" />`
   - `<meta name="twitter:card" content="summary_large_image" />`

---

## Validation Scenario 4: Admin Live Preview

1. Navigate to `http://localhost:3000/admin/blogs/create`.
2. Type a title and toggle 2-3 authors.
3. Observe the live preview card update smoothly with the official logo and selected author avatars without layout jitter.
