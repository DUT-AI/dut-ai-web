## Summary

Enable administrators in `/admin/blogs/create` to import complete blog posts from a Notion export ZIP archive. The system automatically parses the archive in-memory using `jszip`, extracts the page title (clearing Notion's 32-hex ID) and summary, generates a URL-friendly slug with duplicate detection, uploads all embedded image assets directly to MinIO storage under `blogs/`, rewrites relative/URL-encoded image links in the markdown body to public MinIO URLs, and populates the `BlogForm` for author selection and editorial review.

---

## Technical Context

**Language/Version**: TypeScript 5.9, Next.js 16.3.1 (React 19), Node.js 20+  
**Primary Dependencies**: `jszip` (ZIP decompression), `@aws-sdk/client-s3` (MinIO upload), `drizzle-orm` (PostgreSQL query), `lucide-react`, `sonner` (toasts)  
**Storage**: PostgreSQL (via Drizzle ORM for `blogs` and `blog_authors`), MinIO Object Storage (`blogs/` folder)  
**Testing**: End-to-end verification with sample archive `57da3f8a-e1fe-4f43-9d0e-63f9abb55d9b_ExportBlock-722b653a-bd16-4c90-a03f-c6ab043354dc.zip`  
**Target Platform**: Next.js App Router Web Application (Desktop & Mobile Admin)  
**Project Type**: Full-stack Web Application  
**Performance Goals**: Archive processing and batch image uploads complete in < 5 seconds for archives with 10+ images  
**Constraints**: Maximum archive size 50MB; zero disk-based temp file leaks (100% in-memory streaming/buffer processing)  
**Scale/Scope**: Admin-facing import workflow, supporting standard Notion page markdown exports  

---

## Constitution Check
